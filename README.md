# Presentación · Parte II. Estructura Curricular

Diapositivas para exponer con las y los docentes la **Parte II: Estructura Curricular** del
*Plan de Estudio para la Educación Preescolar, Primaria y Secundaria 2022* (Nueva Escuela Mexicana),
correspondiente a las **páginas 81 a 153** del documento.

## Cómo usarla

1. Abre el archivo **`presentacion-estructura-curricular.html`** en cualquier navegador
   (Chrome, Edge, Firefox). No requiere internet ni instalación.
2. Navegación:
   - **→ / Espacio / clic derecho de la pantalla**: siguiente diapositiva
   - **← / clic izquierdo**: diapositiva anterior
   - **F**: pantalla completa (para proyectar)
   - **Inicio / Fin**: primera / última diapositiva
